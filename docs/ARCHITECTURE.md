## Движок (`crates/engine`)

Проверка одного файла (`Engine::scan_file`):

1. **Тип файла** (`filetype.rs`) по сигнатурам заголовка: PE, ELF, Mach-O, ZIP, GZIP, TAR, PDF, OLE, скрипты, текст.
2. **Хэши** (`hashing.rs`) — SHA-256 всегда, SHA-1 и MD5 только если в базе есть такие сигнатуры подходящего размера.
   Поиск в `sigdb::hashdb` (отсортированные массивы + фильтр по размеру), сверка с белым списком.
3. **Сигнатуры содержимого** (`patterns/`): из каждого шаблона выделяется «атом» — самая
   информативная последовательность фиксированных байт. Все атомы ищутся за один проход
   Aho-Corasick, найденные кандидаты проверяются привязанным `regex::bytes`.
4. **Правила** (`rules/`): лексер → парсер → AST → компиляция строк в тот же механизм шаблонов →
   вычисление условий. Нераспознанные правила пропускаются с предупреждением, остальные работают.
5. **Эвристики** (`analyzers/`): имя файла, исполняемые файлы (goblin), скрипты, PDF, Office (OLE и
   OOXML, распаковка VBA по MS-OVBA), APK (бинарный AndroidManifest). Каждая находка даёт баллы,
   сумма сравнивается с порогами уровня: «подозрительно» — от 60 / 40 / 25 баллов (низкий / обычный /
   высокий), «опасно» — от 90 (обычный) и 70 (высокий); на низком уровне эвристика только предупреждает.
6. **Архивы** (`archive.rs`): рекурсивный обход ZIP/GZIP/TAR с лимитами глубины, числа файлов,
   общего распакованного объёма и коэффициента сжатия; каждый вложенный файл проходит шаги 1–5.

Вердикт: сигнатура с важностью ≥ medium → **опасно**, ниже → **подозрительно**,
эвристика — по сумме баллов.

Остальное:

| Модуль | Назначение |
|---|---|
| `scanner.rs` | Обход каталогов (walkdir) в отдельном потоке и пул потоков-проверщиков; пауза, отмена, прогресс; вложенные и повторяющиеся корни отбрасываются, чтобы файл не проверялся дважды |
| `cache.rs` | Кэш чистых файлов (`SCC1`): путь → размер + время изменения; сбрасывается при смене баз или настроек |
| `quarantine.rs` | Хранилище `SCQ1`: ChaCha20-Poly1305 потоками по 1 МиБ, ключ установки в `vault.key`, метаданные в JSON; восстановление с проверкой SHA-256 |
| `realtime.rs` | Наблюдение за папками (`notify`: ReadDirectoryChangesW, FSEvents, inotify, kqueue); файл проверяется, когда запись в него затихает на 0,8 с |
| `update.rs` | Пакет баз `.tar.gz` + `update.json`, подпись Ed25519, установка в `db/current` с сохранением `db/previous` |
| `sigdb/` | Загрузка ClamAV (`.hdb .hsb .hdu .hsu .ndb .ndu .fp .sfp .ign .ign2 .cvd .cld .cud`), YARA, списков хэшей |

### Формат обновлений

`update.json`:

```json
{
  "version": "2026.10.13.1",
  "released": 1791878400,
  "url": "seccom-db-2026.10.13.1.tar.gz",
  "size": 1048576,
  "sha256": "…",
  "signature": "<Ed25519 от байтов пакета, hex>",
  "min_engine": "1.0.0",
  "notes": "необязательно"
}
```

Приложение скачивает пакет (только HTTPS, размер не больше заявленного), проверяет SHA-256 и подпись
встроенным публичным ключом, отклоняет версии не новее установленной, распаковывает во временную
папку, убеждается, что база загружается и не пуста, и переименованием подменяет `db/current`.
Предыдущая версия остаётся в `db/previous` для отката.

## Бэкенд приложения (`app/src-tauri`)

| Файл | Назначение |
|---|---|
| `lib.rs` | Запуск, плагины, трей, автозапуск, единственный экземпляр, сворачивание в трей |
| `commands.rs` | Команды для интерфейса (тяжёлые выполняются в `spawn_blocking`) |
| `state.rs` | Общее состояние: движок, настройки, журнал, угрозы, статистика, карантин |
| `scan.rs` | Проверки: быстрая, полная, выборочная, приложений (Android); события прогресса |
| `realtime.rs` | Защита в реальном времени: монитор движка (Windows, macOS, iOS) или служба Android |
| `updater.rs` | Онлайн-обновление баз каждые 6 часов |
| `scheduler.rs` | Проверки по расписанию (ежедневно / еженедельно, догоняющий запуск) |
| `platform/` | Папки для проверки, исключения, автозагрузка, доступ к диску — по платформам |
| `report.rs` | HTML-отчёт о проверке |

События для интерфейса: `scan://progress`, `scan://threat`, `scan://finished`, `realtime://event`,
`update://progress`, `db://reloaded`, `status://changed`.

Данные приложения (папка `app_data_dir`):

```

scan-cache.bin                          кэш чистых файлов
```

### macOS: защита конфиденциальности (TCC)

macOS охраняет Рабочий стол, Документы, Загрузки, iCloud Drive, данные других приложений, почту и т. п.
Без «Полного доступа к диску» чтение там вызывает системный запрос (а у неподписанной сборки — снова
и снова). Поэтому:

- `platform::macos::has_full_disk_access` молча проверяет доступ, пробуя открыть системную базу TCC
  (без доступа macOS просто отказывает, ничего не спрашивая);
- если доступа нет, ручная быстрая или полная проверка возвращает `fda_required`, и интерфейс
  предлагает открыть настройки, перезапустить SecCom (`restart_app`) или проверить без защищённых
  папок; фоновые проверки (трей, расписание) сразу идут без них, а запись в журнале помечается `limited`;
- защита в реальном времени не следит за защищёнными папками, пока доступа нет;
- файлы и папки iCloud/File Provider, которые лежат только в облаке (флаг `SF_DATALESS`), не читаются,
  чтобы проверка не скачивала облако;
- сборка подписывается (`build/macos/build.sh`): только для подписанного приложения macOS запоминает разрешения.

## Плагин устройства (`plugins/tauri-plugin-seccom-device`)

**Android (Kotlin).** `DevicePlugin` — команды для интерфейса: доступ к файлам, список приложений
с источником установки и разрешениями, удаление и настройки приложения, проверка безопасности
устройства, выбор файла через системный диалог. `ProtectionService` — служба переднего плана
(`specialUse`): следит за папкой «Загрузки» (FileObserver) и установкой приложений
(`PACKAGE_ADDED/REPLACED`), вызывает движок через JNI (`NativeBridge` →
`Java_com_webnetkz_seccom_device_NativeBridge_*` в `platform/android.rs`) и показывает уведомления.
`BootReceiver` перезапускает службу после перезагрузки.

**iOS (Swift).** `deviceSecurity`: код-пароль, Face ID / Touch ID, версия системы.
Файлы попадают в приложение через «Файлы», «Поделиться» и `Documents/Inbox`.

## Интерфейс (`app/src`)

- `store.tsx` — состояние приложения, навигация, тосты, подтверждения, тема и язык.
- `api/backend.ts` — типизированные вызовы команд; вне Tauri подключается `api/mock.ts`
  (демо-данные, параметры `?platform=`, `&lang=`, `&theme=`).
- Вёрстка: боковое меню на компьютере, нижняя панель на телефоне, безопасные зоны iOS/Android,
  CSS без вложенности (Safari 15+).
