## Default Permission

Default permissions for the SecCorp device plugin

#### This default permission set includes the following:

- `allow-get-storage-access`
- `allow-request-storage-access`
- `allow-list-installed-apps`
- `allow-uninstall-app`
- `allow-open-app-settings`
- `allow-device-security`
- `allow-start-protection`
- `allow-stop-protection`
- `allow-protection-status`
- `allow-pick-file`
